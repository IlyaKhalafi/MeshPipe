# Changelog

## 0.3.0

- Added morph-target GLB heads with saved retargeting presets and a bundled example.
- Added non-destructive motion edits, curves, fades, spike removal and take blending.
- Added background browser and Blender exports plus display-free CLI commands.
- Added offline Blender baking with remapping, key reduction and preserved rotation modes.
- Added an interactive static browser studio using genuine recorded face tracking.
- Added procedural face accessories with editable anchors and face-depth occlusion.
- Added adaptive CPU resolution and live cadence controls with measured hysteresis.
- Added landmark-only recordings and protected source previews and capture.
- Added neutral-reference displacement heatmaps with rigid head motion removal.
- Kept version 1 recordings compatible with the version 2 session reader.
- Validated browser desktop and mobile layouts, native workflows and Blender 4.2 baking.

Two-face tracking and downloadable desktop releases are not part of this update.

## 0.2.0

- Added performance replay, local OSC, PNG puppets and view recording.
- Added calibration, UV texture, smoothing inspection and an expression playground.

## 0.1.0

- Introduced the CPU face-mesh pipeline, desktop viewport and geometry exports.
